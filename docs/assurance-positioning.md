2. Security Control Validation — $1,500 fixed scope for one bounded staging scenario; define one consequential operation and expected allow/deny/hold/escalate outcome, exercise the agreed boundary, verify the actual downstream effect, and return reproducible evidence plus the owner decision/retest criterion.

3. Agent Authority & Evidence Primary Audit — $4,900 deeper specialized audit for action-capable AI-agent workflows.

System labels such as finance, voice/CX, legal, hospitality, enterprise AI and agents are examples only. They are not separate BitEvo commercial lines.
